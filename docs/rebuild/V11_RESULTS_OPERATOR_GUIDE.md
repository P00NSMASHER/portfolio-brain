# Portfolio Brain V11: engineering-results evidence

This documentation-only follow-up is an ordinary, **protected** pull request
created after V11 PR #823 merged. It validates that the existing
`v9-guarded-native-automerge` Foundation CI follow-up can publish a new
read-only, sampled engineering-results artifact without any 12-hour observation.

## Where to find the report

In GitHub **Actions**, open a successful `v9-guarded-native-automerge` run
associated with a post-V11 normal PR. Its
`brain-v11-results-<pr-head>-<workflow-run-id>` artifact contains:

- `results.html`: an offline, human-readable evidence dashboard.
- `results.json`: a structured snapshot of the same sampled GitHub evidence.

Only *original GitHub provider facts* may count as protected merges, completed
core runs, or true issuer-pinned independent verification. Coverage is limited
to a bounded recent sample, not a complete historical census.

## Truthfulness and authority

- A successful Foundation job is not a merged PR, production deployment, or
  customer outcome. Both original required App checks must pass on one head.
- The report leaves production-deployment results and actual billing costs
  **UNKNOWN** unless their authoritative receipts exist.
- Old observation issues may be marked as policy-retired, not secretly
  converted into successful historical runs.
- A red or missing report must be visible as such; don't present a CI job
  success as proof that a separate result artifact was produced.
- This guide does not mint an acceptance receipt, alter scheduled tasks,
  request a paid provider, or grant a new action.
