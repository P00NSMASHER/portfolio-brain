# Research, upgrades and repairs

The primary mission is autonomous research and continuous improvement of every
registered current project. Production reliability, correctness, security,
usability, accessibility, maintainability and useful capabilities determine value.
Revenue is optional project-specific evidence, never a global ranking input.

The existing `brain projects` pipeline emits `mission` and `mission_priorities`
for all registered logical projects. Adverse observed checks require diagnosis
and reproduction first. Unknown evidence requires verification, not a success
claim. Equal-evidence projects rotate with the existing persisted cycle index.
The existing bounded source collection and request budgets are unchanged.

Legacy `priority_improvements` remains a specialist RETALLY/Factory handoff for
compatibility; it is not the global mission queue. Its former commercial north
stars are unset. Revenue evidence gates remain solely to prevent false claims
or unauthorized customer activation. Other projects retain their real owners;
this change does not grant a new generic writer or independent reviewer.

Use the closed loop: detect, diagnose, reproduce, research verified sources,
make the smallest useful reversible correction, test, independently verify,
release under actual safeguards, observe deployed behavior, learn. Distinguish
proposed, patched, CI-verified, merged and live-verified throughout. Existing
unattended acceptance, privacy, budget and release holds remain authoritative.

Scheduled Chat owners should use the same mission within their existing lanes,
preserving names, cadence, enabled status, silence and Chat-only requirements.
Plugin availability does not grant runtime API access. No new runtime provider,
spending, contact, credential, schedule or deployment authority is introduced.
